# Project rules: Lasting Words

This repository is for **Lasting Words**, and nothing else. **Before writing,
committing or pushing anything here, check it against these rules.**

## AVA access

AVA is allowed to access, read, edit and write in this repository and work
on its front end and back end.

AVA's own private code, prompts, data, database files and internal docs stay
in AVA's repositories. Only the integration code that lets AVA work on this
project belongs here.

## Keep projects separate

Only Lasting Words content belongs here.

**Do not add code, data, docs, notes or credentials from any other project.**
This repository is **public**: anyone can read it, so never commit anything
private, including the names or details of other projects.

Never commit credentials, API keys, tokens or real environment values. They
go in the hosting provider's environment settings.

**If unsure** whether something belongs here, stop and ask the repo owner
before writing it.

## Changing these rules

Only the repo owner can change these rules. Update this file first, then
write the new kind of content.
